# Echoes of the Fallen

### Third-Person Action RPG | Unreal Engine 5

**Project Status:** Early Development

## About the Game

Echoes of the Fallen is an original third-person action RPG inspired by medieval fantasy and ancient mythology.
The story follows an ordinary human warrior who discovers a mysterious connection to forgotten gods. As ancient creatures awaken, the protagonist must develop his combat skills, unlock divine powers, and uncover the secrets of a fallen kingdom.
The project focuses on responsive combat, character progression, enemy AI, and immersive exploration.

## Technologies

- **Game Engine:** Unreal Engine 5.4.4
- **Visual Scripting:** Unreal Engine Blueprints
- **Programming Language:** C++ (planned)
- **Version Control:** Git and GitHub
- **Large File Management:** Git LFS
- **Target Platform:** Windows PC
